Selenium Maven Project with Cucumber Integration

This project is built using Selenium WebDriver and Maven, with Cucumber integrated for Behavior Driven Development (BDD). It focuses on automating the SauceDemo website — a demo e-commerce platform commonly used for testing automation workflows.

Project Overview:
The main goal of this project is to test the complete user flow of an e-commerce application.

The scenarios covered include:
-Logging into the application

-Adding multiple items to the cart

-Removing one item from the cart

-Completing the checkout process

-Navigating back to the home page

Reports :
After each test run, the framework generates both HTML and JSON reports, providing a detailed summary of the test execution and results.

Tools and Technologies :
Java

Selenium with Maven

Cucumber (BDD Framework)

Purpose : 
This project was created to practice and demonstrate the integration of Cucumber with Selenium and Maven, while automating real-world e-commerce scenarios on the SauceDemo website. It serves as a hands-on example of building a structured, maintainable automation framework.
